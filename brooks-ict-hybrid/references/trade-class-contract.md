# Trade Class Contract — 四级持仓（2026-07-09）

四类持仓级别。**每一笔裁决开口前必须先定类**；类决定周期栈、触发门槛、止损宽度、目标层、管理节奏与仓位单位。触发语言（扫荡 / MSS / 失败突破 / 二次入场 / 回踩守住）四类共用，变的是 TF 与管理合同。

**铁律：持仓中途禁止换类。**

- 日内亏了不变成「趋势拿住」——该打损打损。
- 趋势/周线仓不用日内管理——禁止入场价 BE、禁止见 M15 就砍、禁止把周期仓当剥头皮。
- 若读盘真的变了级别：先 **平掉旧类**，再 **独立评估** 新类，禁止静默改标签。

## 四级总表

| 类（对内 / 对外） | TF 栈 | 持仓时长 | 止损 | 目标 | 管理节奏 | 默认风险单位 |
|---|---|---|---|---|---|---|
| `scalp` **剥头皮** | M1/M5 触发，M15 结构 | 数分钟 | 紧、贴结构（白名单） | **仅近端流动性** | 人在屏前，逐 bar | 0.5 |
| `intraday` **日内** | M15 + H4 偏向，M1/M5  refinement | 数小时 / 当日内 | 结构极 + 0.25×ATR，且 ≥0.5×ATR | 管理位 → 主目标 → runner | 桌面默认模式 | 1.0（READY 对齐） |
| `trend` **趋势** | H4 + D1 偏向 | 数天–数周 | 宽结构损，仓位更小 | HTF DOL + runner 力学 | **日线收盘**复盘为主 | 0.75 |
| `weekly` **周线** | W1 + D1 结构 | 数周–数月+ | 周线结构失效 | 周期目标区分批 | **仅周收盘** | 配置比例（非 R 点） |

本地数据：`GET /bars?symbol=X&tf=M1|M5|M15|H4|D1|W1`（见 `local-stack.md`）。

## 1. 剥头皮 `scalp` — 默认劝退，仅白名单

数学对剥头皮不友好（RR 常倒挂，需很高胜率才活；点差/滑点吃边缘）。本用户成交常落后手点。默认答复：**这不够格当剥头皮**，除非命中白名单：

1. **指数 RTH 开盘扫荡 V 反转**（已验证）：US500/NAS100/US30，开盘窗口扫明显位 + 单根 M1 拒绝，进出只打近端流动性。
2. **`counter_htf` 近端剥**：scanner `counter_htf=true` — 只拿近端流动性立刻走，**禁止**为远 DOL 留仓。

白名单硬条件（全满足）：

- 高参与时段（指数 RTH 开盘；金银/FX 的伦纽重叠）。死清时段 = 不做剥。
- A+ 触发；B 级触发缩仓也救不了剥的数学。
- 表达为**现在可挂**的条件单（fills lag）。
- 禁止 barbwire / extreme_tr 内剥；禁止红字窗口硬剥。
- 同结构 2 次止损 → 停，先重判周期态，禁止第三次同级。

附加：

- **机器信号一律不够格当剥头皮**（2026-07-10 审计：papertrack scalp 腿平均 −0.097R，2R 剥头皮模型在机器信号上证伪）——剥只能来自人在屏前的实时 LTF 触发，scanner 候选想剥也得先过白名单 + 生 bar 重判。
- **摩擦预检**：预期毛利润 ≥ 2× 往返成本（该品种该时段），否则不存在这笔。
- **对齐则升格**：白名单触发若 **HTF 对齐**，默认升格为 **【日内】** 持有（触发可以早，持仓按日内），不要用剥的近端目标把自己踢出去。
- **+1R / 管理位**：剥类触近端即走，不搞 runner。

## 2. 日内 `intraday` — 桌面默认

`SKILL.md` 默认行为 = 日内类：M15+H4 地图、PA 重分类、周期态门、管理位/主目标/runner、挂单优先、五查熔断、Entry Timing Ladder。

要点：

- 止损双约束（结构外 0.25×ATR **且** |entry−SL|≥0.5×ATR）。
- 浮盈到管理位或 +1R（先到）**必须减仓**；移损只到确认结构。LTF 紧损触发单可在**入场时写死** `mgmt2r`（首减 +2R 或第一个对手 M15 结构位，+1R 起结构移损），中途改方案非法（见 execution-gates harvest law variant）。
- counter_htf / 逆 D1：目标封顶近端，无 runner。
- HTF 对齐且跟随仍在：主目标后才 trail runner。
- 日末：若用户有「收盘前平」规则，纳入管理；**周五非加密**：不做周五冻结、正常给单，但闭盘前必须平仓，CFD 不留仓过周末（2026-07-10 用户裁定）。

## 3. 趋势 `trend` — 波段（原 swing）

- **偏向栈**：D1 结构（含 always-in / 关键摆动）压过 H4；H4 逆 D1 = 最多按剥/短持处理，无趋势 runner。
- **入场**：H4/D1 POI 回踩、突破后回踩、D1 顺势限价；扫荡反转要过 D1 优先级门（见 SKILL）。
- **加仓**：仅新结构确认后加，合并后总风险 ≤ 原计划 R；**禁止摊平加仓**。
- **管理节奏**：以 **日线收盘** 为主；盘中不因 M15 噪音改趋势损。盘中只处理：硬止损触达、用户主动问、重大红字。
- **成本**：加密永续持有数周要报 funding 拖累；多头可建议现货。CFD 注意周末跳空。
- **目标**：主目标用 HTF 实用 DOL；runner 用更远 W1/D1 流动性，且跟随仍在。
- **+1R 规则**：趋势类可把「首减」放在更远的管理位（例如 1.5–2R 或首个 D1 结构），但 **必须在计划里写死**，不能进场后再改成「不减」。

## 4. 周线 `weekly` — 投资仓（原 position / 周期仓）

给「从周期低位拿到趋势目标」用。这是 **投资程序**，不是桌面剥/日内；多数桌面反射有害。

硬规则：

1. **现货、无杠杆。** 周期路径常含 50–80% 回撤；永续死于资金费与插针。杠杆「周线仓」= 拒绝规划。
2. **区分批限价，不是点位触发。** 3–5 档吃进周线折价区（前周期高、周线 POI 等）。接受部分成交；禁止追最后一档。
3. **按配置比例仓，不按 1R 点。** 失效可能是 −40% 级；仓位要扛得住 60% 浮亏还不强迫卖。觉得「仓太小没意思」= 仓对了、信念标错价。
4. **管理 = 仅周收盘。** 入场时写死：周线收盘破失效位 或 触及周期目标区（分批减）。周中 M15/scanner/情绪 **无权** 改计划。用户周中问 → **重述书面计划**，不重做 M15 分析。
5. **叙事诚实。** 减半/四年周期 n 极小，不是预测。本模式提供可执行的持有结构，不保证抄到大底。
6. **可与桌面类共存**：同一标的「周线现货 + 日内永续」是两笔独立账，禁止脑子里轧差。

周线类 **不适用** 日内的 +1R 强制减、BE 推进、M5 结构平仓建议——那些是另一类合同。

---

## 选类决策（内心，秒级）

1. 用户点名级别 → 用该级。  
2. 持仓时长意图：分钟 / 当日 / 多日 / 多周+。  
3. 止损自然宽度：噪音级 → 只可能是剥（且过白名单）；要 W1 失效 → 周线。  
4. 逆 HTF/逆 D1 → 最多剥或日内近端，禁止趋势/周线逆大级别硬扛。  
5. 默认：**日内**。拿不准时选日内，不要默默升到趋势/周线。

## 管仓时按类说话

| 类 | 用户说「半死不活」 | 合法动作 |
|---|---|---|
| 剥 | 近端没到可走/损没到拿 | 到近端必须清 |
| 日内 | 损没到拿着；M5 收盘破结构才议平 | +1R/管理位必减 |
| 趋势 | 重述日线计划；不因盘中磨人砍 | 日收盘复盘移损/加减 |
| 周线 | 只重述周计划 | 等周收盘 |
